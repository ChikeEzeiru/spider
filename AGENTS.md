## Working on this site

- **Change only what you're asked to change.** Keep everything the owner has approved (mechanics, motion, timing, layout) exactly as it is, and change only the part requested. If a change needs a previous version, restore that version exactly, then make the one change.
- **Never remove or replace work unless told to.** Add new concepts or versions alongside existing ones. When an instruction about keeping or removing something is ambiguous, ask.
- **Improve what exists before replacing it.** When something approved needs to be better, enhance it; don't swap in a new approach.
